# Audit, 2026-10-01

Code audit of `server/**` and `web/src/**` at `0bc9f70`, in four lenses: security and
scoping, correctness and data integrity, the client, dead code and drift. Every blocker and
major below was reproduced before it was fixed (a failing `bun test`, a curl run or a
Playwright run against a local server on port 3071 seeded into `./data-audit`). Server tests
for the fixed findings are in `server/audit.test.ts`; the survey queue test is in
`web/src/pages/plan/survey/drive.test.ts`.

Severity: **blocker** = security hole or data loss in the field now; **major** = wrong
behaviour a person in the field sees, or a fault that grows over a session; **minor** =
everything else.

## Checked and clean

- **Scoping.** Every tRPC procedure of `shared`, `crew`, `driver`, `green`, `access`, `oneway`
  and `alleys`: crew scope comes from its crew row, driver from its truck, green from the
  session's CC, admin's `x-lrb-cc` is honoured for admin only. Every `admin.*` and `plan.*`
  procedure is `adminProcedure`. Numeric ids are checked against the scope:
  `green.assign` (request CC, truck CC and day), `green.cancel` and `deliver`, `driver.cancel`
  (own truck), lot writes through `checkPlace` (site, day area, crew rectangle), photo
  delete (`canViewLot`, `canDeletePhoto`), rectangle actions (`areaOf` reads only this CC's
  areas), drawn lots, the paint Crew brush, `buildCrews` (company in the event). Anonymous
  requests reach `shared.me`, `shared.authConfig`, `shared.push.key`, `access.link`, `/health`,
  the auth routes and static files only.
- **By design (DECISIONS).** Crews get every event at their CC through `shared.onCc`,
  including other crews' requests and positions; any session of an event can view any lot's
  photos; greens and admin may mark any cached parcel.
- **HTTP.** Cookies HttpOnly, SameSite=Lax, Secure under https; a new session id on every
  sign-in (no fixation); the login limit keys on the trusted `X-Forwarded-For` hop; static
  paths cannot leave `web/dist` (normalised from a rooted path); photo files are named by
  integer id; JPEG magic and SOF checked, 6 MB per file; the `/__/auth` proxy drops `cookie`
  and `host` and has a fixed upstream host; zod caps every array and polygon (paint 500 per
  stroke, polygons 64 and 201 points); all SQL goes through Drizzle parameters, no `sql.raw`.
- **Transactions and events.** `deliverRequests`, `restocked`, `paint`, `undoPaint`, the
  day-of writes, `upsertLots` and Publish emit after commit.
- **Time zone.** Server day logic uses America/Detroit (`detroitDate` in access and photos,
  the zip name); event days are built at UTC noon; client times format in Detroit.
- **Client lifecycle.** Listener, interval and observer cleanup in `MapView`, `DriverMap`,
  `FlagMap`, `paintStroke`, `drawPolygon`, `orientedRect`, `position.ts`, `useCamera`,
  `useCompass`, `useFix`, `Nav`, `PhotoViewer`. Sign-out and leave reload and clear IndexedDB,
  session storage and the remembered role. Every route group ends in a redirect and every
  Suspense has a fallback. No endless reconnect on UNAUTHORIZED.
